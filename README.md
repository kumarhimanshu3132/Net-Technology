## 💻 How to Run (For Console & Web Applications)

To run the C# experiments locally on your machine, follow these steps:

1. Clone this repository.
2. Open the terminal and navigate to the specific experiment/project folder:
   `cd Experiment1` (or `cd Experiment9/PlacementDashboard`)
3. Run the application using the .NET CLI:
   `dotnet run`
