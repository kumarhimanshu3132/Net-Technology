## 💻 How to Run (For Console Applications)

To run the C# Console experiments locally on your machine, follow these steps:

1. Clone this repository.
2. Open the terminal and navigate to the specific experiment folder:
   cd Experiment1
3. Run the application using the .NET CLI:
   dotnet run
