# Practical 1: Student Admission Management

**AIM:** Develop Student Admission Management Module using OOP Concepts (Class, Object, Constructor, Access Modifiers).

## Description
This C# console application manages the student admission process. It collects basic student information and securely validates the 10th and 12th percentages (minimum 55% required). Eligible students can select a program (B.TECH, BBA, BCA, M.TECH, MBA, MCA) along with their respective streams. The system calculates scholarships based on 12th-grade performance and provides options to opt for Bus (monthly) and Hostel facilities. The final fee is dynamically calculated based on the chosen payment mode (Yearly or Semester-wise).

## How to Run
1. Open the terminal in the project directory.
2. Execute the following command:
   `dotnet run`
