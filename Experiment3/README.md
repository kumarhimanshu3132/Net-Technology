# Experiment 3: Expense Tracking Module

**AIM:** Develop Expense Tracking Module with Exception Handling.

## Description

This C# console application implements a full-featured Expense Tracking System with robust data validation and custom exception handling. It utilizes custom exception classes (`ExpenseTrackerException`) along with built-in format exception handling to ensure strict data integrity (non-future date validation, positive amount checks, non-numeric description checks). The system supports payment categorization (Cash, UPI, Cards, NetBanking), sorting expenses chronologically, month & year filtering, and full CRUD operations (Add, View, Edit, Delete).

## How to Run

1. Open the terminal in the `Experiment3` directory.
2. Execute the following command: `dotnet run`
