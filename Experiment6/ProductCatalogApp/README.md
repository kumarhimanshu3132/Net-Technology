# Experiment 6: Product Catalog Application

AIM: Create Product Catalog Application using ASP.NET MVC Architecture (Controllers, Models, Views, Routing).

## Description

This project demonstrates the core Model-View-Controller (MVC) architectural pattern in ASP.NET Core. It implements strongly-typed Product models, controller actions for catalog browsing and filtering, Razor views for dynamic rendering, and custom URL routing rules.

Key Features:

- Clean separation of concerns following the **MVC Architecture** (`Models`, `Views`, `Controllers`).
- Dynamic product listing, category filtering, and detailed product view pages.
- Strongly-typed Razor views displaying product specifications, pricing, and stock status.
- Configured conventional and attribute routing in `Program.cs` for clean, SEO-friendly URLs.

## Technologies Used

- ASP.NET Core MVC (.NET 8.0)
- C# & Razor View Engine
- HTML5 / CSS3 / Bootstrap 5
