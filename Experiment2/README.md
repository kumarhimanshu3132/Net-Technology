# Experiment 2: Corporate HR & Payroll Dashboard

**AIM:** Design Employee Payroll System using Inheritance, Interface & Polymorphism.

## Description
This C# console application implements an Enterprise-level Employee Payroll System. It uses an `IPayrollSystem` interface and an abstract base class `Employee`. The `FullTimeStaff` class inherits from the base class and demonstrates polymorphism by implementing specific salary calculations and pay slip generation. The system features a monthly payroll processing mechanism with leave deduction logic and strict Regex validations for data integrity.

## How to Run
1. Open the terminal in the `Experiment2` directory.
2. Execute the following command:
   `dotnet run`
