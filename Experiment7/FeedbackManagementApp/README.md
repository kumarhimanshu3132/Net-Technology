# Experiment 7: Feedback Management Module

AIM: Develop Feedback Management Module using MVC Layout, Partial View & Validation (HTML Helpers, Validation, Layouts).

## Description

This project implements a structured Course/Campus Feedback Management Module in ASP.NET Core MVC. It focuses on reusable UI architecture using shared Layouts and Partial Views, form building with Strongly-Typed HTML/Tag Helpers, and strict client-side and server-side model validation.

Key Features:

- Consistent application theme and navigation powered by shared `_Layout.cshtml`.
- Modular and reusable UI components implemented via **Partial Views** (e.g., feedback summary cards and alert banners).
- Interactive feedback submission form built using **HTML Helpers / Tag Helpers**.
- Comprehensive **Data Annotations** (`[Required]`, `[EmailAddress]`, `[Range]`, `[StringLength]`) with unobtrusive client-side validation.

## Technologies Used

- ASP.NET Core MVC (.NET 8.0)
- C# & Razor Views
- jQuery Validation & Bootstrap 5
