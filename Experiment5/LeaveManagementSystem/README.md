# Experiment 5: Academic Calendar & Leave Management System

AIM: Develop Academic Calendar & Leave Management System using Rich Controls, Session & Cookies.

## Description

This project implements an interactive Academic Calendar and Student/Faculty Leave Management portal using ASP.NET Web Forms. It utilizes Rich Server Controls (Calendar, MultiView/Wizard) alongside client-side and server-side state management techniques (Cookies and Session State) to persist user preferences and track leave applications.

Key Features:

- Interactive Academic Calendar control highlighting holidays, exam schedules, and working days.
- Leave application workflow with date range selection and leave balance calculation.
- **Session State** management to securely store active user login details and submitted leave records across postbacks.
- **Cookies** implementation to remember user preferences and last-visited portal settings.

## Technologies Used

- ASP.NET Web Forms (.NET Framework)
- C# (Backend Logic & State Management)
- HTML/CSS (UI Design)
