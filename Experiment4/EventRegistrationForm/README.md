# Experiment 4: Event Registration Portal

**AIM:** Develop a professional Event Registration Portal using ASP.NET Web Forms.

## Description

This project implements a web-based registration form utilizing ASP.NET Server Controls (TextBox, DropDownList, Button) and Validation Controls (`RequiredFieldValidator`, `RegularExpressionValidator`).

**Key Features:**

- Strict client-side and server-side data validation (Regex for Email, Phone, Enrollment limits).
- C# backend logic for string manipulation (Regex space trimming and Title Case formatting).
- Configured `UnobtrusiveValidationMode` for seamless UI error handling.

## Technologies Used

- ASP.NET Web Forms (.NET Framework)
- C# (Backend Logic)
- HTML/CSS (UI Design)
